# W2A artifact contract v1.0

## Layout (relative to `research_runs/ai_witness_followup_2026_09/w2a/`)

| Path | Content | When |
|---|---|---|
| `design/` | Frozen design: this contract, protocol, method, prompts, analysis, execution plan, changes, config, W1 input pins, verifier, `DESIGN_FREEZE.sha256` | design freeze |
| `w2a.py`, `w2a_harness/` | Harness and tests; copied W1 modules recorded in `prep/provenance.json` | package freeze |
| `schedule.json` | Seeded eight-session schedule (regenerates byte-identically) | package freeze |
| `prep/` | Offline reports, each stamped with the code hash: `offline_tests.json`, `dry_run.json`, `w1_regressions.json`, `render_check.json` with `rendered/` (model-facing first-stage texts), `budget_check.json`, `provenance.json`, `w1_audit_reproduction.json` | before the package freeze |
| `prep/gates.json` | Latest preflight output (regenerated by each run; not frozen) | any time |
| `PACKAGE_FREEZE.sha256` | Hashes of code, tests, schedule, design manifest, W1 pins and offline reports | offline gates pass |
| `launch_config.json` | Resolved provider fields, smoke record, pricing confirmation and authorizations; no secrets | smoke and after |
| `launch_record.md`, `LAUNCH_FREEZE.sha256` | Gate table at launch; hashes of the package freeze, launch config and record | all gates pass |
| `events.jsonl`, `resources/resource_ledger.jsonl` | Append-only hash-chained event and resource ledgers (`w2a-event/1`) | smoke onward |
| `measured/w2a.<case>.<F2 or F3>/` | Requests and responses, proposals, builds, traces, `stages/`, `final.json`, `session.json`, `validation/` | measured run |
| `raw_seal.sha256` | Hashes of `measured/` and both ledgers, written before analysis | after collection |
| `analysis/` | `results.json`, `report.md` from the frozen analysis | after the seal |
| `work/` | Local build scratch (git-ignored, not evidence) | runtime |

## Identifiers

- **Sessions:** `w2a.<case>.<arm>`.
- **Requests:** `<session>.reqNN`.
- **Proposals:** `<session>.pN`, shown to the model as `pN`.
- **Search pairs:** `<proposal>.pairN.<variant>`.
- **Validation attempts:** `<session>.val.<variant>.t<k>.a<j>`.

## Ledger envelope

The envelope is W1's, with schema identifier `w2a-event/1`: schema version, sequence, UTC, stage, event type, entity id, previous hash, payload and its own SHA-256 over canonical JSON. The genesis hash is 64 zeros. Every append is fsynced before completion is claimed.

## Event types

Event types added beyond W1's:

- `admission_denied`
- `response_truncated`
- `stage_output_rejected`
- `stage_plan`
- `stage_judgments`
- `final_call_result`
- `growth_bound_exceeded`
- `upper_bound_exceeded`

## Record requirements

- **Session records** carry: terminal reason, reason codes, calls by stage, tokens, USD, counters, admission denials, stage records, proposal states, pairs, and the sealed final without file bodies.
- **Request records** carry: exact request bytes and hash, admission kind and reserve held back, returned model, stop reason, usage breakdown (input / cache write / cache read / output / thinking), USD with pricing identity, and status.

## Git policy

Commit design, code, tests, schedule, `prep/` reports and freezes after review. `work/` and `__pycache__/` stay ignored. Raw measured records and ledgers are experiment evidence: commit or archive them only by an explicit researcher decision, never with credentials. W1 files are never written by W2A.
