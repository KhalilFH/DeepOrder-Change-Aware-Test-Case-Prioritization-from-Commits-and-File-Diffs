# W2A design v1.0

Frozen design for the W2A execution-feasibility pilot: four exposed W1 development cases × plain (F2) and structured (F3) Claude Sonnet 5 agents, one session each, no Jev.

| File | Governs |
|---|---|
| [PROTOCOL.md](PROTOCOL.md) | question, fixed design, isolation, terminal accounting, stop rules, amendments |
| [METHOD_CONTRACT.md](METHOD_CONTRACT.md) | shared facilities, reserves, F2/F3 algorithms, stage acceptance |
| [PROMPTS.md](PROMPTS.md) | exact model-facing texts (parsed verbatim) |
| [ANALYSIS_PLAN.md](ANALYSIS_PLAN.md) | feasibility table, attrition, Gate 1 and Gate 2, decisions |
| [ARTIFACT_CONTRACT.md](ARTIFACT_CONTRACT.md) | layout, identifiers, ledgers, records |
| [EXECUTION_PLAN.md](EXECUTION_PLAN.md) | commands, launch sequence, resource bounds |
| [DESIGN_CHANGES.md](DESIGN_CHANGES.md) | material changes from proposal v0.1, with evidence; residual risks |
| [MEASURED_RUN_PROMPT.md](MEASURED_RUN_PROMPT.md) | the researcher's launch instruction |
| `study_config.json`, `w1_inputs.json` | machine-readable settings; read-only W1 artifact pins |

Authority: PROTOCOL.md controls design and endpoints; METHOD_CONTRACT.md controls arm behavior; ANALYSIS_PLAN.md controls interpretation; `study_config.json` repeats numbers for machine use. A disagreement is a freeze defect to resolve by amendment, not an invitation to choose.
