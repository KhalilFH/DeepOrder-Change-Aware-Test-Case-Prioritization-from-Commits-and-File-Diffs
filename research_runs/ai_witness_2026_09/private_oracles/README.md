# W1 private oracles

Validator-only material. Method processes never receive these files: provider requests are
rendered from `inputs/<case>/` packets only, and `packet.leak_scan` rejects renderings that
mention this directory or oracle vocabulary.

- Rule code: `w1_harness/oracles.py` (engine plus one class per case; `ORACLE_VERSION = w1-oracle/1`).
- Per-case specification: `private_oracles/<case>/ORACLE.md`.
- Synthetic classifier-logic fixtures: `private_oracles/<case>/fixtures/` with `expected.json`
  (generated by `w1_harness/oracle_fixtures.py`). They test classifier logic, not defect
  behaviour, and are not positive controls.
- Frozen before calibration (2026-09-26). No rule was tuned on calibration or historical outcomes.

Attempt statuses: PASS, FOCAL_FAILURE, NONFOCAL_FAILURE, UNRESOLVED, HARNESS_INVALID, NOT_RUN.
A FOCAL_FAILURE needs a failing attempt plus premise and consequence evidence locators
(`trace:<sha256>:L<a>-L<b>` or, only for unchanged supplied tests, `source:<path>@<sha256>:L<a>-L<b>`).
Exit status, arbitrary assertion text or an elapsed timeout alone are never sufficient.
Ad hoc human overrides are not allowed during collection.
